# Chat Mobile App 💬

A mobile chat application built with **React Native, Expo, and TypeScript**. The project focuses on creating a clean, modern messaging interface with reusable components and a user-friendly experience.

## 🚀 Technologies Used

- React Native
- Expo
- TypeScript
- Expo Router
- React Native Components
- Expo Vector Icons

## ✨ Features

- Modern chat application interface
- Reusable UI components
- Contact list interface
- Message list interface
- Custom header component
- Icon buttons using Ionicons
- Pressable components for interactive UI elements
- Responsive mobile layout

## ⚙️ Installation and Setup

### 1. Clone the repository

git clone https://github.com/nokuphiwa02/Chat_Mobile_React_Native.git

### 2. Navigate to the project folder

cd Chat_Mobile

### 3. Install dependencies

npm install

### 4. Start the Expo development server

npx expo start

To run using Expo Go with a tunnel:

npx expo start --go --tunnel

## 📱 Running the Application

1. Install Expo Go on your mobile device.
2. Start the development server.
3. Scan the QR code displayed in your terminal.
4. Open the application on your mobile device.

## 🎨 UI Components

The application uses reusable components to keep the code organised and maintainable.

- **Header:** Displays the application header.
- **ContactList:** Displays contacts and their profile images.
- **MessageList:** Displays the messaging interface.
- **Button:** Reusable button component with icons.
